# 부동산 시세·권리·리스크 통합관리 시스템

AI 활용 AX경진대회 출품작. 금융회사의 대출심사/담보리스크 관리 업무를 보조하는 AI 웹 도구입니다.
심사를 대체하는 시스템이 아니라, **심사역의 판단을 돕는 참고 도구**로 포지셔닝합니다.

상세 요건 정의는 [docs/개발요건서.md](docs/개발요건서.md) 참고.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 백엔드 | Python, FastAPI, SQLAlchemy |
| 프론트엔드 | React, TypeScript, Vite, Recharts |
| ML | XGBoost, scikit-learn |
| LLM | Claude API (미설정 시 템플릿 기반 생성으로 자동 폴백) |
| DB | SQLite (초기) → PostgreSQL (추후 전환 예정) |
| 배치 | APScheduler |
| 외부 연동 | 국토교통부 실거래가 API, 카카오맵 API, 온비드(KAMCO) 공공데이터포털 API, 네이버 뉴스 검색 API, 네이버부동산(Playwright 스크래핑) |

## 개발 우선순위

1. **기능1 (시세추정 + 담보 리스크 스코어링)** — 완성도 있게 구현
2. **기능2 (등기부등본 권리분석)** — 프로토타입 수준
3. **기능3 (감정평가 유사사례 검색)** — 샘플 데이터 기반 데모

공식 API가 없는 데이터(낙찰가율, 등기부등본 등)는 초기엔 샘플/더미 데이터로 화면과 로직부터 구현하는 것을 원칙으로 합니다.

## 화면 구성 (업무 프로세스 기반)

```
물건 검색/등록 → 종합분석 화면(핵심) → 심사의견 초안 생성 → 심사역 검토·수정 → 결재 상신 → 사후 모니터링
```

AI가 생성한 심사의견은 항상 "AI 초안"으로 구분 표시되며, 심사역이 수정할 수 있고 수정 이력(AI 초안 vs 심사역 최종본)이 남습니다.

## 현재까지 구현된 기능

### 기능1. 시세 추정 + 담보 리스크 스코어링 ✅
- 국토교통부 실거래가 Open API 연동 (매매/전월세), 주소·단지명 검색은 카카오맵 API로 좌표·법정동코드 변환
- XGBoost 기반 시세 추정 모델 (신뢰구간 포함)
- 규칙 + ML 하이브리드 담보 리스크 스코어링 (카테고리별 기여도, 1~10 등급)
- 네이버부동산 매물 수집 (Playwright 스크래핑, 차단 시 샘플 데이터로 자동 폴백) 및 실거래가 대비 호가 괴리율 비교

### 기능2. 등기부등본 권리분석 (프로토타입) ✅
- PDF/이미지 업로드 → OCR/텍스트 추출 → 근저당권·가압류 등 권리유형 자동 분류
- LTV, 권리관계 요약, 리스크 플래그 표시 (Claude API 연동, 미설정 시 템플릿 기반 요약으로 폴백)
- "참고용 분석이며 최종 판단은 전문가 검토 필요" 면책 문구 포함

### 기능3. 감정평가 유사사례 검색 (샘플 데이터 기반) ✅
- 온비드 공매 감정평가서 PDF 파싱 → 소재지/면적/용도/단가 메타데이터화
- 신규 물건 입력 시 지역·용도·면적 유사도 기반 유사사례 검색 및 참고 감정가 제시
- "참고용 추정치이며 실제 감정평가와 차이가 있을 수 있음" 면책 문구 포함

### 통합 기능 ✅
- LLM 기반 심사의견 자동 생성 — AI 초안 / 심사역 최종본 구분 및 수정 이력 관리
- 대시보드 — 물건별 시세·리스크 등급·권리관계·이상 매물 알림을 한 화면에 표시

### 데이터 수집 배치 (신규) ✅
- **온비드 공매 물건·감정가** 수집 → 원본 테이블 적재, 물건관리번호 기준 중복 방지
- **네이버 뉴스 검색 API**로 부동산 정책 관련 뉴스 수집 → 기사 링크 기준 중복 방지
- APScheduler로 매일 새벽(기본 03:00) 자동 실행, 실행 로그(수집/중복/실패 건수) 별도 기록
- **온비드 지역별 입찰 통계** — 시도별 입찰 건수·낙찰률·평균 낙찰가율 추이 화면, 종합분석 화면 요약 카드 연동 (주 1회 자동 수집). 실제 API 서비스/오퍼레이션명이 아직 확정되지 않아 현재는 샘플 데이터로 화면·로직을 검증하는 단계이며, 확정되는 대로 설정값만 교체하면 바로 연동됩니다.

## 실행 방법

```bash
# 백엔드
cd backend
python -m venv .venv && source .venv/Scripts/activate  # Windows
pip install -r requirements.txt
cp .env.example .env  # 발급받은 API 키 입력
uvicorn app.main:app --reload

# 프론트엔드
cd frontend
npm install
npm run dev
```
