# 부동산 시세·권리·리스크 통합관리 시스템 개발요건서

## 1. 프로젝트 개요
- **과제명**: AI 기반 부동산 시세·권리·리스크 통합관리 시스템
- **추진 배경**: 금리 변동성 확대와 부동산 시장 등락으로 담보가치·리스크에 대한 정교한 판단 필요성이 커지고 있으나, 실무 업무에서는 물건지별 시세·권리관계·감정사례를 개별 확인해야 해 시간이 많이 소요되고 담당자 경험에 따른 판단 편차가 존재함. 공신력 있는 시세 정보는 KB부동산, 한국부동산원 등 제한적 기관에 의존하고 있어, AI를 활용한 신뢰성 있는 시세 추정 및 리스크 판단 체계 마련이 필요함. 이에 부동산 평가 관리 시스템을 통해 업무효율화는 물론 신뢰도 높은 분석정보를 토대로 영업채널 확대 및 리스크관리를 도모하고자 함.
- **목표**: 부동산 매물 하나에 대해 시세 추정 → 담보 리스크 평가 → 권리관계 분석 → 유사 감정평가 사례까지 종합 분석하고 심사의견을 자동 생성하는 웹 시스템

## 2. 전체 아키텍처
```
데이터 수집(실거래가/공시지가/낙찰가율/네이버부동산/등기부/감정평가서)
   → 시세 추정 엔진 (ML)
   → 리스크 스코어링 엔진 (규칙 + ML 하이브리드)
   → 권리분석 엔진 (등기부 파싱)
   → 유사 감정평가 검색 엔진 (RAG)
   → LLM 기반 심사의견·리스크 통합 생성기
   → 웹 대시보드 (시각화 + 알림)
```

## 3. 기술 구현 내용
1. 국토교통부 실거래가, 공시지가, 낙찰가율, 네이버부동산 매물 및 실거래가 데이터 수집·정제
2. 수집한 데이터 기반으로 ML 모델(XGBoost 등) 기반 시세 추정 엔진 구축
3. 지역·단지규모·평형·시세·낙찰가율 추이 반영한 규칙+ML 하이브리드 담보 리스크 스코어링(1~10 등급)
4. 등기부등본 업로드 시 해당 물건 현황 및 근저당·가압류 등 권리관계 자동 분석
5. 공매·경매 첨부 감정평가서 학습, RAG 기반 유사지역·유사사례 검색 및 참고치 제시
6. LLM 기반 심사의견서, 리스크 자동 생성 (시세·리스크·권리·감정사례 종합)
7. 담당자용 대시보드 구축 (시세/낙찰가율 등 심사지표 시각화, 이상 매물 알림)

## 4. 기능별 상세 요구사항

### 기능1. 시세 추정 및 담보 리스크 스코어링
- 데이터 소스: 국토교통부 실거래가 Open API, 공시지가 API, 낙찰가율(수집 방식 검토 필요), 네이버부동산(호가/매물 심리 파악용)
- 시세 추정: XGBoost/LightGBM 등으로 지역·평형·층수·준공연도·거래량 등 반영
- 리스크 스코어링: 지역, 단지 규모, 낙찰가율 추이, 전세가율 등을 반영한 규칙+ML 하이브리드 로직
- 출력: 추정 시세(신뢰구간 포함), 리스크 등급(1~10 등급)

### 기능2. 등기부등본 권리분석
- 입력 방식: 등기부등본 파일 업로드(PDF/이미지)
- 처리: OCR/문서파싱 → 근저당권·가압류·가등기 등 권리유형 자동 분류, 물건 현황 확인
- 출력: 권리관계 요약, 투자가치 판단, 리스크 요인 설명 (LLM 생성)
- 유의사항: "참고용 분석이며 최종 판단은 전문가 검토 필요" 면책 문구 포함

### 기능3. 감정평가 유사사례 기반 추정 가이드
- 데이터 소스: 온비드(공매) 등 공개 경매·공매 공고에 첨부된 감정평가서
- 처리: 감정평가서 파싱(소재지, 면적, 용도, 평가일, 단가) → 메타데이터 DB화
- 검색: 신규 물건 입력 시 지역·용도·면적 유사도 기반 유사사례 검색(RAG)
- 출력: 유사사례 목록 + LLM 기반 참고 감정가 및 판단 근거 설명

### 통합 기능. 심사의견 자동 생성 및 대시보드
- LLM이 기능1~3 결과를 종합해 표준 양식 심사의견서 및 리스크 요약 자동 작성
- 대시보드: 매물별 시세 추이 차트, 리스크 등급 뱃지, 권리관계 요약, 유사 감정사례를 한 화면에 표시
- 알림: 이상 매물(급락/권리하자 등) 발생 시 알림 기능

## 5. 기술 스택 제안
- 백엔드: Python (FastAPI 등)
- ML: XGBoost/LightGBM, scikit-learn
- LLM/RAG: Claude API + 벡터DB(임베딩 검색)
- 프론트엔드: 웹 대시보드 (React 등)
- DB: PostgreSQL(정형 데이터) + 벡터DB(뉴스/감정평가서 텍스트)

## 6. 개발 우선순위 (MVP 범위)
1. **1순위**: 기능1(시세 추정 + 리스크 스코어링) — 데이터 확보 용이, 대회 완성도 핵심
2. **2순위**: 기능2(등기부 권리분석) — 프로토타입 수준 데모
3. **3순위**: 기능3(감정평가 유사사례) — 샘플 데이터 기반 데모

## 8. 용어 설명 (참고용)
- **ML(머신러닝) 모델**: 과거 데이터의 패턴을 학습해 새로운 입력에 대한 결과를 예측하는 기술. 과거 실거래가를 학습해 신규 매물 시세를 예측하는 데 활용.
- **XGBoost**: 대표적인 ML 알고리즘 중 하나. 여러 개의 예측 모델을 순차적으로 보완하며 정확도를 높이는 방식. 정형 데이터(지역, 면적, 층수 등) 예측에 강하고, 변수별 영향도 설명이 가능해 심사 근거 제시에 유리함.
- **LLM(거대언어모델)**: 방대한 텍스트를 학습해 자연스러운 문장을 생성·이해하는 AI 기술(예: Claude, ChatGPT). 여기서는 분석 결과를 종합해 심사의견서를 자동 작성하는 데 활용.
- **RAG(검색증강생성)**: LLM이 답변을 생성하기 전에 관련 데이터(유사사례, 뉴스 등)를 먼저 검색해 그 내용을 근거로 답변하는 방식. 유사 감정평가 사례 검색 및 설명에 활용.
